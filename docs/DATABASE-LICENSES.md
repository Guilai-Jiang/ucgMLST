# Database licensing

The ucgMLST code is licensed under GPL-3.0-or-later (see `LICENSE` and
`COPYING`). The reference data are a separate work with their own terms. Before
redistributing the database bundle, confirm the terms below.

| File | Origin | When publishing |
|---|---|---|
| `staph_aureus.cgMLST`, `MLSTdb0.1.fasta`, `new_profile_md5.csv`, `new_HierCC.HierCC` | Core-genome scheme, allele reference and HierCC profiles assembled for the CC398 study (Jiang et al., *mSystems* 2026). HierCC method: Zhou et al., *Genome Research* 2021. | Cite the study and the HierCC paper. Confirm with the corresponding author and the journal data policy that redistribution is allowed. |

If redistribution is not permitted, publish the code only and let users supply
their own database directory with `--db`.

## Citation

- Jiang G, et al. Large-scale genomic analysis places Chinese CC398 as a
  persistent human-associated MSSA lineage apart from the dominant global
  LA-MRSA clade. *mSystems*. 2026;11(10). doi:10.1128/msystems.00621-26
- Zhou Z, Charlesworth J, Achtman M. HierCC: a multi-level clustering scheme
  for assignment and population genetics. *Genome Research*. 2021.
